Isomorphic
Channel Sorting

Offline topological permutation of a neural network's weight matrix, so standard block quantization just works — no runtime sparse-gather, no FABQ-RC patching, single contiguous memory read on a mobile NPU.

01Why FABQ-RC breaks on a phone

Mobile NPUs are bound by unified-memory bandwidth, not raw FLOPs. The runtime cost isn't the math — it's the fetches.

FABQ-RC at runtime

Two memory streams — dense base weights and a sparse residual codebook — are fetched separately, then stitched via branching logic or sparse addition. Each token's forward pass pays the cache-miss cost on every layer.

# FABQ-RC forward, per layer
y = matmul(x, W_base)        # dense fetch
idx, rcode = lookup_residual(x)
y += scatter_add(rcode, idx) # sparse gather

What ICS delivers instead

One monolithic INT4/INT2/INT1 weight tensor. Outliers are pre-sorted next to other outliers, so the per-block scaling factor α never crushes normal weights. Single sequential read, no branching.

# ICS at runtime, per layer
y = matmul(x, W_packed)      # one fetch, no gather

02The identity that makes it free

The permutation cancels algebraically. The model's outputs are bit-identical to the un-permuted model, modulo FP roundoff.

Y = X · (WA PT) · (P WB) = X · WA · WB
P is an orthogonal permutation matrix, P−1 = PT. Forward-pass-exact, by construction.

All the cleverness is in which P we pick. The pipeline sorts channels so that high-Fisher (loss-sensitive) channels AND high-magnitude outliers land in the same dense blocks — which then get INT4 precision. The low-importance tail gets INT2/INT1.

What the runtime needs

Either: a custom NPU kernel that consumes the packed INT4/2/1 layout directly (the speedup case), or the verification path — dequantize_blockwise() reconstructs a dense fp32 weight tensor that loads into any HF model with zero code change.

08What it is not

Not a fine-tuning framework

The permutation is locked after calibration. Re-training the model post-ICS would diverge from the original training trajectory — that is the limit of the offline trick.

Not a perplexity competitor to GPTQ / AWQ

ICS is a topology change, not a better quantizer. Combined with INT4/2/1, expect accuracy in the same ballpark as any mixed-precision block-quant scheme. The new perplexity harness is for verification and comparison; the current checked-in numbers are CPU smoke results, not a full benchmark claim.

Not a complete shipping artifact

This repo gives you the offline permutation + the packed safetensors. The NPU-side kernel that consumes the packed INT4/2/1 layout at runtime is a separate piece of work tied to CoreML / QNN / NNAPI.
